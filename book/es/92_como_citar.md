# Cómo citar

Si utilizas este material, por favor cítalo de la siguiente manera.

## Cita recomendada (APA 7.ª edición)

> de la Iglesia, D. H. (2026). *Guía para elaborar una revisión sistemática de la literatura (SLR)*. Universidad de Salamanca. https://github.com/danihiglesias/guia-slr

## BibTeX

También puedes usar el archivo BibTeX descargable: {download}`citation.bib <../_static/citation.bib>`.

```bibtex
@book{de_la_iglesia_guia_slr_2026,
  author = {de la Iglesia, Daniel H.},
  title = {Guía para elaborar una revisión sistemática de la literatura (SLR)},
  year = {2026},
  publisher = {Universidad de Salamanca},
  url = {https://github.com/danihiglesias/guia-slr}
}
```

```{note}
Cuando el libro se deposite en Zenodo, esta página se actualizará con el DOI definitivo.
```
