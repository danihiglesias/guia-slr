# How to cite

If you use this material, please cite it as follows.

## Recommended citation (APA 7th edition)

> de la Iglesia, D. H. (2026). *Guide to conducting a systematic literature review (SLR)*. University of Salamanca. https://github.com/danihiglesias/guia-slr

## BibTeX

You can also use the downloadable BibTeX file: {download}`citation_en.bib <../_static/citation_en.bib>`.

```bibtex
@book{de_la_iglesia_guide_slr_2026,
  author = {de la Iglesia, Daniel H.},
  title = {Guide to conducting a systematic literature review (SLR)},
  year = {2026},
  publisher = {Universidad de Salamanca},
  url = {https://github.com/danihiglesias/guia-slr}
}
```

```{note}
When the book is deposited in Zenodo, this page will be updated with the definitive DOI.
```
