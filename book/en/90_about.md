# About

This book is a practical guide to conducting a systematic literature review (SLR) or a systematic mapping study in engineering and computer science, aimed at PhD students and researchers undertaking their first review. It was written as support material during the PhD and covers the current standards, an overview of tools and a section on the responsible use of generative AI.

Citation information is gathered on the [How to cite](92_how_to_cite.md) page.

## How this book is made

This site is written in Markdown files and converted to HTML and PDF using tools from the [TeachBooks](https://teachbooks.io/), [Jupyter Book](https://jupyterbook.org/) and [MyST Markdown](https://mystmd.org/) ecosystem, based on the [TeachBook USAL template](https://github.com/elloza/teachbook_usal_template) by Álvaro Lozano Murciego and André Filipe Sales Mendes.

The source files are in a public GitHub repository:

- https://github.com/danihiglesias/guia-slr
